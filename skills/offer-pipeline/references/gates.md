# Gate checklists

Each gate is a list of lines. A gate passes when every line is true. When one fails, say which line and what would
make it pass.

## Gate 1: niche

- [ ] The niche names a buyer you can list: a role or business type and a size ("online shops with 200+ SKUs").
- [ ] `niche_score.py` gives SHIP (11 or more after caps).
- [ ] Channel has an exact query, list or community, written down.
- [ ] Pain has a quote in the buyer's words and 3 or more named instances.
- [ ] Money names what they pay today and to whom.
- [ ] Kill criteria written: what you would have to see to drop this niche.

## Gate 2: reality check

- [ ] `reality_check.py` verdict is GO or TEST.
- [ ] Top 3 failure modes each have a test or a fix.
- [ ] "Do nothing" or the manual workaround is on the competition list.
- [ ] Effort in weeks and the reward in plain words are on the card.
- [ ] Red-flag claims removed or backed.

## Gate 3: positioning

- [ ] Competitive alternatives listed from the buyer's view, including the status quo.
- [ ] Unique attributes each have proof you can show.
- [ ] Value themes say what the attributes let the buyer do.
- [ ] Best-fit buyer is narrower than the niche (from `icp_traits.py` if you have deals).
- [ ] Market category chosen, with its style (head-to-head, big fish in a small pond, or a new category).
- [ ] Lead claim is WHITE SPACE, or CONTESTED with proof, in `claim_triage.py`.
- [ ] The angle passes all 7 lines of the angle gate (see the `positioning-map` references).

## Gate 4: value stack

- [ ] `value_equation.py` exits 0.
- [ ] Every stack item kills a named objection.
- [ ] Guarantee has a name, a number, a window and a consequence.
- [ ] Mechanism has a name a rival could not say word for word.
- [ ] Any scarcity has a real reason written beside it.

## Gate 5: price

- [ ] One price point, not a range.
- [ ] Value metric named (per shop, per seat, per month, per project), and it grows with the value the buyer gets.
- [ ] Anchor named: the cost of the problem or of the alternative, in the buyer's own numbers.
- [ ] If tiers: the middle one is the one you want sold, and tiers differ by outcome, not by feature count.
- [ ] Top 3 price objections, with an answer each.

## Gate 6: page

- [ ] `offer_page_lint.py` exits 0.
- [ ] One call to action.
- [ ] Read out loud once by a human; anything they stumbled on is rewritten.

## Gate 7: validation

- [ ] GO and KILL lines written in the decision log before the test started.
- [ ] Visitors or conversations reached the planned number.
- [ ] `validation_calc.py judge` says GO, or paid pre-orders reached their line.
- [ ] The decision and the reason are in the log, dated.
